# ToDo
Currently this has both the computer version, can be found in release 1, Deadlines 1.0, and the most up to date mobile version on latest release, only on andriod and can be downloaded with the .APK file.

- Current features include in the app:  
  -Adding deadlines  
  -Seeing deadlines on a calander  
  -Connecting to Canvas assignments  
  -Widget possible to add to home screen  
  -Dark and Light mode in addition to adapting to system light mode.

## Mac
The computer version also runs on Macs (Apple silicon, macOS 13 or newer), with the same features and look.

- Download `Deadlines.dmg`, open it and drag Deadlines into Applications.
- The first time, macOS will say it can't check the app (it isn't from the App Store). Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

Building it: on a Mac run `bash build_mac.sh`, or on GitHub go to **Actions → Mac app → Run workflow** and download `Deadlines-mac` from the finished run.
